# Font

`m5x7.png` is the m5x7 pixel font by Daniel Linssen (managore), https://managore.itch.io/m5x7
(CC0; attribution appreciated). It is the 16 by 6 ASCII sheet (codes 32 to 126, 8 by 9 pixel cells,
7 rows above the baseline) from the BOK's `Assets/Fontm5x7.png`, converted to white ink on a
transparent background so the page can tint it. The page measures each glyph's width at load, so
text is proportional.
